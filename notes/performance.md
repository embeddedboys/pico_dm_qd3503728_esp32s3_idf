# 性能实测

> 历史 32 KB 帧上限配置测得 EP1 约 `0.947 MB/s`、局部刷新约 `100 FPS`、全屏分带约 `6 FPS`。

## TL;DR

- 测试对象是 ESP32-S3 + ILI9488、QOI、协议 v2、USB Full-Speed。
- 编码在计时循环外完成，结果主要反映 USB 和设备端刷新。
- 大载荷受 USB 带宽限制，全屏小载荷仍受分带/面板刷新开销影响。
- 当前源码为 64 KB 帧上限、Octal PSRAM、CPU1 解码，尚未重新测量；以下保留历史基线。

## 适用边界

纯色全屏单次传输约 `121 FPS`，只是协议/设备基准，不代表当前驱动的分带刷新路径。
更换 USB 拓扑、固件配置、面板或编码器后必须重新测量。

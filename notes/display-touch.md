# 显示与触摸

> 结论：ILI9488 使用 `480x320` 逻辑坐标，FT6236 和 TSC2007 可通过同一组引脚自动探测。

## TL;DR

- 面板原生尺寸 `320x480`，`TFT_ROTATION=1` 后对主机报告 `480x320`。
- FT6236 地址为 `0x38`，TSC2007 地址为 `0x48`。
- TSC2007 的按下、释放和坐标已通过 EP4 验证，FT6236 兼容代码保留。

## 显示

ILI9488 通过 LovyanGFX 16-bit 8080 总线驱动，像素格式 RGB565。面板原生尺寸是
`320x480`，当前旋转值 `TFT_ROTATION=1` 后，主机协议逻辑尺寸为 `480x320`。

此前使用原生 `320` 作为 QOI 分带宽度校验会拒绝宽度为 `480` 的所有横屏分带；当前
解码器校验和能力报告都使用旋转后的逻辑几何。

## 触摸控制器

`main/board_touch.c` 保留 FT6236 支持并新增 TSC2007 支持：

1. 初始化 I2C。
2. 优先探测 FT6236 地址 `0x38`。
3. 探测失败后尝试 TSC2007 地址 `0x48`。
4. 使用共享的 SDA/SCL/IRQ 引脚。
5. 触摸任务每 `10 ms` 读取一次并通过 EP4 上报。

两种控制器均经过代码路径保留；TSC2007 的实际按下、释放和坐标报告已通过 EP4
轮询/推送测试验证。FT6236 的兼容支持没有移除。

## 坐标验证

当前主机报告的逻辑坐标范围是 `480x320`。更换屏幕或旋转值后，应先读取 caps，
再用 `tests/touch_test.py` 验证轴序、反向、按下和释放，不应直接套用旧校准值。
